# Inside Java

**Understand Java from the inside out.**

Inside Java is an open-source interactive educational platform that explains Java and JVM internals through detailed technical visualizations, interactive diagrams and simulations.

## What You'll Learn

- Java source code to bytecode execution
- JVM architecture and class loading
- Runtime memory areas
- Heap, stack and object memory
- Garbage collection algorithms
- Java collections internals
- Multithreading and concurrency
- JIT compilation and HotSpot internals
- JNI and native integration
- JVM performance and diagnostics

## Core Principles

- Technically accurate explanations.
- Custom SVG-based technical visualizations.
- Beginner-friendly learning paths.
- Interactive component inspection.
- Clear separation between JVM specifications and implementation details.
- Free and open-source learning resources.

## Development

The application is planned as a static website.

There will be no backend, database, paid APIs or paid hosting.

Local development instructions will be added once the application foundation is scaffolded.

## Testing

The project will use unit tests and browser automation to validate application behavior, accessibility and visual interactions.

## Deployment

The website will be deployed using GitHub Actions and GitHub Pages.
